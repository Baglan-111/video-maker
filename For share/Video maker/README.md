# Video Maker — скилл для Claude Code

Собирает вертикальные ролики двумя способами: озвучивает сценарий через
ElevenLabs или строит сторителлинг поверх уже снятого видео — субтитры по
словам, графические врезки, цветокоррекция, нормализация звука.

Главное здесь не шаблоны, а **машинная приёмка**. Пятнадцать проверок считают то,
что человек на кадре не видит: отставание субтитров от речи, разрывы звуковой
волны, врезки, въезжающие пустыми. Каждая проверка появилась после дефекта,
который дошёл до зрителя.

## Что внутри

```
Video maker/
├── SKILL.md          — сам скилл: потоки, правила монтажа, приёмка
└── engine/
    ├── src/          — шаблоны Remotion, дизайн-токены, детекторы дефектов
    ├── scripts/      — сборка, рендер, приёмка, цветокоррекция, работа со звуком
    ├── tests/        — 143 теста на детекторы и разбивку субтитров
    └── docs/         — заметки по отдельным пайплайнам
```

## Требования

- **Node.js 20+** и **ffmpeg** в PATH
- **Распознаватель речи** — нужен только для монтажа снятого видео. Скрипт
  выбирает сам, что установлено:
  - `pip install mlx-whisper` — быстрый, **только macOS на Apple Silicon**
  - `pip install openai-whisper` — медленнее на процессоре, **работает везде**:
    Windows, Linux, Intel-Mac

  Больше нигде привязки к платформе нет: Remotion, ffmpeg, приёмка и
  цветокоррекция кроссплатформенны
- **Ключ ElevenLabs** — только для режима синтеза речи. Кладётся в
  `~/.config/elevenlabs/.env` строкой `ELEVENLABS_API_KEY=...`.
  В репозитории ключей нет
- **Лицензия Remotion** — сам пакет ставится автоматически, отдельная установка
  не нужна. Но лицензия платная для компаний больше трёх человек; физлицам и
  небольшим командам бесплатно: <https://remotion.dev/license>

## Установка

Одна команда. Скрипт проверит, чего не хватает, поставит недостающее, соберёт
движок, положит скилл в Claude Code и пропишет пути.

```bash
git clone https://github.com/Baglan-111/video-maker.git
cd video-maker/"For share/Video maker"
sh install.sh          # покажет, что будет сделано
sh install.sh --yes    # сделает
```

Без `--yes` скрипт ничего не устанавливает — только печатает план. Повторный
запуск безопасен: уже установленное он пропускает.

**Через Claude Code**, если не хочется возиться с терминалом. Открой Claude Code
в пустой папке и вставь:

> Склонируй https://github.com/Baglan-111/video-maker.git, зайди в папку
> `For share/Video maker`, покажи мне план из `sh install.sh`, а после моего
> «да» выполни `sh install.sh --yes` и сообщи результат.

Что скрипт делает:

1. Ставит `node`, `ffmpeg`, `python3`, если их нет (через brew на macOS, apt на
   Linux; на Windows скажет поставить вручную).
2. Ставит распознаватель речи: `mlx-whisper` на Apple Silicon, `openai-whisper`
   на остальных системах.
3. `npm install` в движке — вместе с ним ставится **Remotion, отдельно его
   качать не нужно**. Следом скрипт подтягивает браузер, которым Remotion
   рендерит (около 190 МБ): иначе первый ролик встал бы на несколько минут без
   объяснений, а без интернета упал бы. Дальше прогон тестов. Должно быть **142 пройдено, 0
   упало**; один тест пропускается, он смотрит на локальный проект — это норма.
4. Копирует `SKILL.md` в `~/.claude/skills/video-maker/` и подставляет туда
   полный путь к движку. Раньше это был ручной шаг, и про него забывали — Claude
   потом не находил скрипты.

После установки открой Claude Code и напиши: «собери ролик из видео <путь к
файлу>».

**ElevenLabs не нужен**, если монтируешь снятое видео. Ключ требуется только для
роликов с синтезированной речью и кладётся в `~/.config/elevenlabs/.env` строкой
`ELEVENLABS_API_KEY=...`.

## Чего здесь нет

- **Готовых ассетов.** Векторные фигуры (дом, палатка) нарисованы кодом, но
  музыки и исходных видео в репозитории нет — только реестр лицензий и
  тестовый тон.
- **Публикации.** Скилл отдаёт mp4 и останавливается.
- **Написания сценария.** Отдельная задача, отдельный инструмент.
- **Проверки на Windows и Linux.** Код кроссплатформенный, но автор гоняет его
  на macOS — на других системах путь с распознаванием не проверялся живьём.

## Почему приёмка устроена именно так

Ролик один раз был объявлен готовым после просмотра семи кадров. В этот момент
субтитры отставали от речи на всех семи стыках сцен, а в звуковой дорожке
другого ролика вместо речи был цифровой шум — и он тоже прошёл проверку
громкости, потому что нормализация одинаково охотно нормализует и шум.

Вывод, на котором стоит весь `check.mjs`: **пункт чек-листа, который выполняется
«на глаз» или «на слух», в конвейере не выполняется никогда.** Либо величина
считается машиной, либо процесс останавливается и зовёт человека — третьего
варианта нет. Комментарии в коде сохраняют, какой именно дефект породил каждую
проверку; это не история ради истории, а объяснение, почему порог такой, а не
круглый.
